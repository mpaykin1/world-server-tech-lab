# GRAPHICS-DEMO-001 · Artistic Asset Upgrade V11 (эксперимент)

**Источники:** оригинальный игровой мир пользователя + V10.1 landscape/animation-v2. Никакого нового движка, платного API или фона.

## Реальные изменения

- 13 дополнительно авторски детализированных спрайтов/атласов под `assets/art-v11` (дом, шахта, мост, камень, фасетные утёсы, вода, цветы/папоротники/мох и три разновидности анимированных спрайтшитов каждого из двух видов деревьев).
- Слою `art-v11.js` разрешены максимум 90 декоративных штампов на кадр, нет ни одного нового таймера или собственного RAF. Он встраивается ПОСЛЕ animation-v2.js.
- У старых персонажей, дорожек, коллизий, оригинального 52×28 мира и импорта ассетов та же логика. Прежние PNG остаются в полном ZIP для точного отката; новые файлы лежат отдельно.
- В Chromium проверено 4 точки (деревня, мост, шахта, лес) на 1200×780 и 390×844, проверены keyboard и Chromium simulated touch, отсутствие console/page errors.

## Воспроизведение и откат

1. Распаковать ZIP, открыть `medieval_world_infinite_pack_v3/demo.html` в браузере или локальном статическом сервере (без установки третьего движка).
2. `python tools/test_v11_art.py` и остальные `python tools/test_*.py`, `node --check art-v11.js`.
3. Chromium harness `python tools/run_v11_chromium.py` требует `playwright`, Pillow и браузер chromium; сравнение использует SHA-pinned исходный V10.1 ZIP из Library. В headless среде движок не заменяется.
4. Для отката взять оригинальный V10.1 ZIP. Арт-графика не затрагивает игру вне экспериментального пакета.
