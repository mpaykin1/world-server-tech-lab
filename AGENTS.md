# Tech Lab Agent Contract

- Канонический основной проект: https://github.com/mpaykin1/World_server
- Основная память: https://github.com/mpaykin1/World_server/issues/80
- Вход: https://github.com/mpaykin1/World_server/blob/master/AI_START_HERE.md
- Не начинай проект заново. Не копируй World Server в лабораторию целиком.
- Каждый эксперимент имеет отдельную ветку и воспроизводимые тесты. Запрещён самовольный merge в World Server.
- Источник лицензий/версия фиксируются до копирования кода или ассетов.
- Никаких новых часовых автозадач, платных API и бесконтрольных фоновых процессов.
- После тестов пользователь сам решает PASS/FAIL. До решения `user_decision = null`.
- Лаборатория — поставщик проверенных модулей; World Server — единственный runtime/production.
- Зафиксируй точный SHA, команду проверки и доказательства. Не объявляй % без измеренного evidence.
